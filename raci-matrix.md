# RACI Matrix

Defines who does what for each task or deliverable. Exactly **one A (Accountable)** per row — if two people are accountable, nobody is.

- **R — Responsible:** does the work
- **A — Accountable:** owns the outcome, gives final approval (exactly one per row)
- **C — Consulted:** asked for input before the work is done
- **I — Informed:** told about the outcome after the fact

## Template

| Task / Deliverable | [Role 1] | [Role 2] | [Role 3] | [Role 4] |
|---|---|---|---|---|
| [Task 1] | R | A | C | I |
| [Task 2] | A | R | I | C |
| [Task 3] | C | A | R | I |

## Worked example — website relaunch

| Task / Deliverable | Client | Project Lead | Developer | Designer |
|---|---|---|---|---|
| Approve page structure | A | R | C | C |
| Implement frontend | I | A | R | C |
| Provide page content | R | A | I | I |
| Final go-live decision | A | R | C | I |

Reading the example: the **Developer** is Responsible for implementing the frontend, the **Project Lead** is Accountable (owns the outcome), the **Designer** is Consulted beforehand, and the **Client** is Informed afterwards.

## Common mistakes

1. **Two A's in one row** — split the task or escalate.
2. **Everyone is C** — consulting five people on everything slows decisions to a crawl.
3. **Nobody is I** — people find out too late and feel blindsided.

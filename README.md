# PM Toolkit

A practical collection of IT project management templates and guides — the documents I actually use to run projects at CloudLift Tech. Bilingual where it matters (English / Deutsch).

## Templates

| Template | Description |
|----------|-------------|
| [Project Charter](templates/project-charter.md) | Bilingual (EN/DE) — project goals, scope, stakeholders, timeline, sign-off |
| [RACI Matrix](templates/raci-matrix.md) | Who does what: Responsible, Accountable, Consulted, Informed — with a worked example |
| [Risk Register](templates/risk-register.md) | Track risks with probability, impact, owner, and mitigation — with example rows |
| [Status Report](templates/status-report.md) | Bilingual (EN/DE) weekly status report — progress, blockers, next steps |

## How to use

1. Copy the template you need into your project repo or docs.
2. Fill in the bracketed `[placeholders]`.
3. Delete the instructional notes (marked with 💡) before sharing.

## Principles

- **One page beats ten.** Every template fits the essentials on as little space as possible.
- **Written beats remembered.** If it isn't written down, it wasn't decided.
- **Boring is good.** Project management succeeds through consistency, not creativity.
